## 書き方

- ファイル名は「骨子の項番_テーマ.md」にする
- 冒頭に、作成日・改訂の内容・対象（骨子の項番と、そのときの commit）と、「骨子の正本ではない」ことを書く
- 調べた範囲・扱っていないこと・確かさと、出典を残す
- 骨子に反映したら、メモの冒頭とこの表の「骨子への反映」を更新する
- 調査メモを足した・直したら、skill の references/ の該当テーマのファイルに要点を反映する
- 調査のための言葉（製品名、「連動」など）は、骨子・スライドには持ち込まない
