# 3章 勘定科目：用語

骨子 3章（固定資産に関係する勘定科目）と、勘定科目の言葉を使うときに読む。仕訳例で使う勘定科目名は [4_伝票の種類.md](4_伝票の種類.md)。骨子・スライド・ノートの言葉はこの定義に合わせる（使い方は SKILL.md）。

## 用語の定義

| 用語 | 本資料での意味 | 使い方の注意 |
|---|---|---|
| 資産勘定 | 建物・機械装置などの勘定。間接法で表示する資産では取得価額、直接法で表示する資産では帳簿価額を記帳する | 「取得価額の勘定」と限定しない |
| 固定資産勘定 | 資産勘定・減価償却累計額・減損損失累計額の総称 | 台帳と元帳の一致の対象。「固定資産勘定の行」は、これらの勘定の行を指す |
| 減価償却累計額・減損損失累計額 | それぞれの累計額の勘定 | 「累計額」だけではどちらか分からないため、省略しない。減損の表示は一般の会計用語の「直接控除形式」「間接控除形式」を使い、「累計額方式」「直接控除方式」とは書かない |
| 費用・収益の勘定 | 減価償却費・売却損益・除却損などの、PL（損益計算書）の勘定 | 簿記の「損益勘定」（決算で収益・費用を集める集合勘定）と紛らわしいため、「損益勘定」とは呼ばない。「損益」だけで書くときは、業績としての利益・損失を指す |
| 債権・債務 | 未払金・未収入金（後で支払・入金する債務・債権）（1-4） | 本資料では、固定資産の取得・売却で出る未払金・未収入金を指す。保険の「掛金」と紛らわしいため「掛け金」とは書かない |
| 仮勘定 | 2つのシステムが1つの取引の仕訳を分担するときに、両方の仕訳をつなぐために使う勘定。取得仮勘定・売却仮勘定・資産計上待ちの仮勘定（購買管理・経費精算システムとの間）・建設仮勘定（1-4） | 建設仮勘定は工事・プロジェクト管理システムの勘定で、固定資産勘定には含めない。固定資産システムは完成時に資産勘定へ振り替えて消し込む |
| 減価償却 | 有形・無形固定資産の減価償却 | 繰延資産は「償却」、長期前払費用は「費用化」と書く。仕訳の形は同じなので、減価償却費の節（骨子 4-5・4-6）でまとめて扱う |

## 統一する書き方（左の表記は使わない）

| 使わない | 使う |
|---|---|
| 損益勘定 | 費用・収益の勘定（「損益」単独は業績としての利益・損失、勘定科目名「売却損益」だけ） |
| 償却費 | 減価償却費（勘定科目名の例「ソフトウェア償却費」「繰延資産償却」は可） |
| 償却（有形・無形の処理） | 減価償却（繰延資産は「償却」、長期前払費用は「費用化」） |
| 累計額（単独） | 減価償却累計額／減損損失累計額 |
| 減損累計額 | 減損損失累計額 |
| 掛け金 | 債権・債務 |
| 資産勘定（3勘定の総称として） | 固定資産勘定。建物・機械装置などの勘定だけを指すときが資産勘定 |
| 科目 | 勘定科目（「補助科目」「財務諸表の科目」は可） |
| 相手方 | 相手勘定 |
