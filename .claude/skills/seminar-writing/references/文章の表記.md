# 用語：文章の表記

特定のテーマによらない、文章の書き方の言葉。骨子・スライド・ノートの言葉はこの定義に合わせる（使い方は SKILL.md）。

## 用語の定義

| 用語 | 本資料での意味 | 使い方の注意 |
|---|---|---|
| 方針・設定 | 方針＝ユーザーが決める会計処理のやり方、設定＝システムのマスタ（資産の種類ごとの勘定科目の対応など） | － |

## 統一する書き方（左の表記は使わない）

| 使わない | 使う |
|---|---|
| 設例 | 例 |
| 仕訳の例 | 仕訳例 |
| 方針によらない原則 | 仕訳の要件 |
| 方針によって変わる点を「バリエーション」の見出し・箇条・列に分ける | 説明の中に、ありうるケースを「〜することも、〜することもある」と並べて書く |
| 「〜はユーザーによる」「〜は方針による」「（方針・設定による）」「〜するユーザーもある」 | 書かない。ケースを「〜することも、〜することもある」と並べる |
| 期待結果 | 期待される仕訳 |
