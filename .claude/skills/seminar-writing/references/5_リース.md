# 第3回 リースの仕訳：用語と仕訳例の決まり

第3回の骨子（`第3回_リース/00_骨子.md`）を書くときに読む。第1回の用語（固定資産勘定、費用・収益の勘定、債権・債務、仮勘定、照合、セグメントなど）は、第1回の references のとおりに使い、ここでは定義し直さない。

## 範囲（2026-11-28）

- 借手だけを扱う。新リース会計基準（企業会計基準第34号）を前提にし、旧基準（ファイナンス・リース／オペレーティング・リース、賃貸借処理）からの移行の仕訳は扱わない
- 第1回の要件（①〜③）と入力項目は参照するだけにし、繰り返さない。各節では、第1回と同じところ（参照）と、リース特有の違い（説明）を分けて書く
- 金額の計算（リース期間の判定、割引率・現在価値、利息の配分）、リースの識別と判定、貸手・サブリース・セール・アンド・リースバック、法人税の申告調整は扱わない

## 用語の定義

| 用語 | 本資料での意味 | 使い方の注意 |
|---|---|---|
| 使用権資産・リース負債 | 新リース会計基準の一般の会計用語。使用権資産＝原資産を使う権利、リース負債＝リース料の支払義務 | 言いかえない。「リース資産」「リース債務」は旧基準の言葉なので使わない |
| 使用権資産減価償却累計額 | 使用権資産の減価償却累計額 | 第1回と同じく「累計額」だけで書かない |
| リース台帳 | 固定資産システムが、リースの契約ごと・物件ごとに使用権資産とリース負債を管理する台帳 | 第1回の「台帳」（固定資産台帳）と区別するときに使う。システムは「固定資産システム」のまま |
| 時の経過で作る仕訳 | 台帳で取引を登録しなくても、リース台帳の予定に沿って決まった時期に作る仕訳（減価償却・支払・流動・固定の振替） | 第1回の定型仕訳と同じ考え方 |
| リース料仮勘定 | リース料の支払で、固定資産システムと相手のシステムの仕訳をつなぐ仮勘定 | 第1回の取得仮勘定と同じ役割 |
| 費用を組み替える形 | 1-4 の3つ目の分担の形。相手のシステムが請求書に基づきリース料を支払リース料・外注費などの費用として計上し、固定資産システムがリース負債・支払利息に組み替える | 「振替」は勘定科目の付け替えの意味で使っているので、この形は「組み替え」と書く |
| 動産リース・不動産リース・実質リース | 一般用語として、普通の意味で使う（実質リース＝業務委託などの、契約の名前はリースでないがリースを含む契約）（2026-11-28） | 本資料で定義する言葉として扱わず、特別な意味を持たせない。「隠れリース」は使わず、実質リースと書く |
| 伝票の種類（リース） | 開始・支払・減価償却・流動・固定の振替・変更・終了・短期リース・少額リース | 「開始」は第1回の取得、「終了」は除却・売却に当たる。「再測定」は一般の会計用語だが、伝票の種類の名前は「変更」とする |

## 仕訳例の決まり

- 勘定科目名：使用権資産、使用権資産減価償却累計額、リース負債（流動・固定に分ける例だけ「リース負債（流動）」「リース負債（固定）」）、支払利息、未払利息、解約損益、変更による損益、リース料仮勘定、前払リース料、資産除去債務。支払リース料は、相手のシステムが計上し固定資産システムが組み替える費用（1-4 の費用を組み替える形）だけに使い、短期リース・少額リースの費用は賃借料とする。不動産リースの支払に加わる行は共益費・支払賃料（歩合）、実質リースの役務の分は外注費（2026-11-28）
- 取引先：リース会社（動産リース）、貸主（不動産リース）、委託先（実質リース）
- セグメント：第1回と同じ（事業X・事業Y、製造1課・販売1課など）
- 基本の例は、間接法で表示し、リース負債を流動・固定に分けず、リース負債にも使用権資産と同じセグメントを持たせる場合

## 調査で分かったこと：リースの支払（調査メモ：第3回_1-4_リースの支払.md）

検索結果の要約にもとづく（原文は未確認）。敷金・差入保証金、建設協力金を除いて、骨子の 1-4・2-1・3-3 に反映した（2026-11-28）。

- 支払の仕訳の基本の形は、動産・不動産・実質リースで同じ（(借) リース負債・支払利息 ／ (貸) 未払金または預金）。違いは、支払の伝票に混ざるリース負債以外の行、消費税の時点、支払を誰が計上するかに出る
- 不動産：共益費・管理費（サービス部分）、歩合賃料（変動リース料。リース負債に含めず発生時に費用）、敷金・保証金、建設協力金との相殺が同じ支払に混ざる
- 実質リース：業務委託料・外注費として請求・支払され、役務部分は外注費のまま、資産を使う部分だけを使用権資産・リース負債にする
- 消費税：税務上の売買は引渡し時にまとめて控除、税務上の賃貸借（不動産、旧基準のオペレーティング・リース、短期・少額リース）は支払の都度控除。会計上は区分しないので、契約ごとに税務上の区分を持つ必要がある
- システムの組み合わせ：A リース資産管理が支払の仕訳を作り、総勘定元帳と支払管理に渡す。B 支払管理・購買管理で支払リース料（外注費）として計上し、リース資産管理が新基準の仕訳に組み替える（債務管理の業務を変えない）。C 不動産は賃貸借契約管理システムが家賃の支払と仕訳のパターンを持つ
- Bの形は、第1回 1-4 の2つの分担の形にない形。組み替える費用の勘定が、仮勘定と同じく2つのシステムの仕訳をつなぐ役割になる（推定）
