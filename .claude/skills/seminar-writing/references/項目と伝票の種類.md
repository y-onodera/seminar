# 用語：項目と伝票の種類

仕訳の入力項目（セグメントなど）と、伝票の種類の言葉。骨子・スライド・ノートの言葉はこの定義に合わせる（使い方は SKILL.md）。

## 用語の定義

| 用語 | 本資料での意味 | 使い方の注意 |
|---|---|---|
| セグメント | 勘定科目以外で、仕訳の集約先となる項目（事業・部門・プロジェクト・取引先など） | 製品によって意味が違う（Oracle EBS では勘定科目を含む勘定組合せの各要素、SAP では外部報告用の特定の項目）。外部報告のセグメントは「外部報告セグメント」と呼んで区別する |
| 用途 | 資産を利用する部門の区分（製造・販売・管理など） | 減価償却費の勘定科目を、用途別に分けるユーザーがある |
| 振替 | 伝票の種類としては、台帳の資産の種類・セグメントの変更による固定資産勘定の付け替え | 一般には勘定間の付け替え全般を指す。ほかの付け替えは「減価償却費の振替」のように対象を付けて書く |
| 伝票の種類・資産の種類 | 伝票の種類＝取得・売却・振替・除却・減損・圧縮記帳・減価償却・過年度の訂正の区分。ERPでは［伝票の種類］の項目で持つ（持たない・まとめるユーザーもある）。資産の種類＝建物・機械装置などの区分 | 「仕訳の種類」とは書かない。有形固定資産・無形固定資産などの区分は「分類」と呼ぶ |
| 伝票番号・参照番号 | 伝票番号＝伝票を識別する番号。参照番号＝元の取引や連携元のシステムで採番した番号 | 採番のしかたは要件次第。「ERPで伝票番号を採番し、固定資産システムで採番した伝票番号は参照番号に入れる」は事例が多い形として書き、決めつけない |
| 記帳日・取引日 | 記帳日＝会計期間を決める日、取引日＝取引が発生した日 | 製品によって呼び方が違う（例：転記日付・計上日、伝票日付・証憑日付） |

## 統一する書き方（左の表記は使わない）

| 使わない | 使う |
|---|---|
| 事業部 | 事業 |
| PJ、プロジェクト・案件 | プロジェクト（例の値「PJ-a」は可） |
| 分析軸 | 切り口 |
| 利用セグメント | 用途 |
| BS・PL | BSとPLのセグメント |
| 属性（台帳の） | 台帳の資産の種類・セグメント |
| セグメント資産 | 外部報告セグメントごとの資産 |
| 仕訳の種類 | 伝票の種類 |
| 振替範囲、振替仕訳 | 振り替える範囲、振替の仕訳 |

## 仕訳例のセグメント

BS＝事業（事業X・事業Y）、PL＝部門・プロジェクト（製造1課・販売1課・PJ-a・PJ-b）。
